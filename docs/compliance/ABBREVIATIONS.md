# Project abbreviations

This table supports BARR-C 1.5.b. Extend it when an owned interface introduces a
project-specific abbreviation; a listed abbreviation does not excuse an unclear
variable or function name.

| Term | Meaning |
| --- | --- |
| ABI | Application binary interface; fixed calling conventions and object layout. |
| ADC | Analog-to-digital converter. |
| BCAP | Barcode sensor capture used for trace and replay diagnostics. |
| BSP | Board support package. |
| CR1 | Change Requirement 1, minimum-bit data representation. |
| CYW43 | Pico W wireless chipset/driver family. |
| FIFO | First-in, first-out queue. |
| FSM | Finite-state machine. |
| GPIO / GP | General-purpose input/output pin. |
| IMU | Inertial measurement unit. |
| IR | Infrared reflectance sensor. |
| ISR | Interrupt service routine; distinguish it from a normal RTOS callback. |
| MQTT | Message Queuing Telemetry Transport. |
| PID | Proportional, integral and derivative controller. |
| PIO / SM | RP2040 programmable I/O / its state machine. |
| PWM | Pulse-width modulation. |
| RTOS | Real-time operating system. |
| S1-S5 | The five team subsystem numbers. |
| SDK | Software development kit. |
| UF2 | Firmware transfer container used by the RP2040 bootloader. |
| USB CDC | USB communications device class serial console. |

Use unit suffixes consistently: `us` microseconds, `ms` milliseconds, `mm`
millimetres, `m` metres, `mps` metres per second, `deg` degrees, and `pct` percent.
Keep range/resolution documentation beside any stored or encoded measurement.

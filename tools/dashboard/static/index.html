Controller, timing & shared resources

The optional IR_DEBUG firmware reports controller decisions, wheel feedback, brake status and observed IR sampling gaps. It does not measure stop latency, task execution time, stack/heap usage or queue occupancy. USB diagnostics and real-car timing tests are still needed. Empty or stale graphs are not evidence that a subsystem is healthy.
